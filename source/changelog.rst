Список изменений
================

**Версия 2.25 от 29.06.2026**

- Создание набора тайлов из MBTiles.
- Предпросмотр сервиса без браузерного кэша.
- Информация об обновлениях на странице "О программе".
- Установка языка пользователя в профиле.

**Версия 2.24 от 26.05.2026**

- Охват по умолчанию для сервиса NextGIS Web устанавливается из ограничивающего охвата веб-карты вместо начального.
- Убрана настройка размера тайла внешнего сервиса. Поддерживаются тайлы только 256x256 px.
- Небольшие улучшения стабильности и обработки ошибок.

**Версия 2.23 от 27.04.2026**

- Новый тип сервиса: набор тайлов.
- Создание API ключа при регистрации пользователя OAuth.
- Выбор API-ключа для шаблонов URL.
- Исправлен максимальный масштаб по умолчанию в диалоге создания API-ключа.
- Исправлена ошибка при входе по OAuth.
- Исправлена ошибка при редактировании профиля пользователя.

**Версия 2.22 от 31.03.2026**

- Поддержка формата WebP для внешних сервисов.
- Исправлено сидирование внешних сервисов с СК EPSG:3857.
- Исправлено удаление тайлов из Redis при сидировании.
- Упрощены url-пути страниц сервисов.
- Очищение прав на сервисы для удалённых пользователей и групп.
- Улучшена целостность внутренней БД.

**Версия 2.21 от 17.12.2025**

- Исправлены отсутствующие символы пробела в шрифтах.
- Замена не поддерживаемых шрифтов на Open Sans.
- Поддержка прокси HTTP(S).
- Проверка соединения с NGW в healthcheck.

**Версия 2.20 от 1.11.2025**

- Добавлена оценка хранилища.
- Атрибуты MVT `name_{lang}` теперь содержат конкретный язык.
- Отображение масштаба на странице предпросмотра.
- Показ статусов сидирования на странице обзора.
- Подсказки для OSM PBF.
- Удалён старый рендерер.
- Исправлено получение групп OAuth.
- Удалён вход по LDAP.

**Версия 2.19.0 от 21.07.2025**

- Отображение сидирующихся сервисов на странице обзора.
- Очистка тайлового кэша при удалении сервиса.
- Исправлен рендеринг тайлов сервисов базовой карты и NGW на некоторых масштабах.
- Исправлена инвалидация растрового тайлового кэша.
- Исправлены слои подписей в стилях по умолчанию.
- Исправлено создание сервисов NGW из веб-карты с пустым охватом.
- Исправлена кнопка очистки данных базовой карты.

**Версия 2.18.0 от 14.05.2025**

- Добавлен выбор из 3 стилей при создании базовой карты.
- Улучшена аутентификация, доработана проверка прав на сервисы.
- Сокращено количество языков в слоях MVT до "name", "name:en", "name:ru".
- Улучшена производительность генерации векторных тайлов.
- CORS для домена "maplibre.org" разрешён по умолчанию.
- Улучшена стабильность функционала сидирования.
- Исправлена блокировка метатайлов, улучшена обработка ошибок кэширования.

**Версия 2.17.0 от 10.03.2025**

- Добавлен слой "landcover" для базовой карты.
- Добавлен шрифт OpenSans.
- PBF-символы всех системных шрифтов доступны по API.
- Автообновление базовой карты выключено по умолчанию.
- Исправлен рендеринг тайлов базовой карты по краям системы координат.
- Исправлена видимость масштабов в сервисах NGW.
- Исправлено создание API-ключей со сроком жизни.
- Множество исправлений сидирования.
- Собственный контейнер Redis на основе Ubuntu 24.04.
- Экспериментальная поддержка рендерера Maplibre GL.
