System requirements
====================

To install NextGIS GeoServices On-Premise you need a physical or virtual server.

It is possible to use the same server where NextGIS Web and NextGIS ID are deployed, but to avoid conflict the server must not be used for other tasks (as file or mail server, PostGIS server etc).

.. _nggs_sys_req_hardw:

Minimum hardware requirements
-----------------------------------

Recommended configuration:

* CPU: 4-core
* RAM: 16 GiB
* Storage: 250 GB SSD

.. _nggs_soft_req:

Recommended OS
---------------------------------

The server must have a Linux-based operational system allowing to install Docker Engine 23 and up, for example:

* Ubuntu LTS 24.04, 22.04, 20.04
* Debian 12, 11
* CentOS 9
